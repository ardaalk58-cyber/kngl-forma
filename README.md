## Proje Hakkında

Bu proje, lise eğitimim sırasında web geliştirme alanında
kendimi geliştirmek amacıyla hazırladığım temel seviyede
bir e-ticaret sitesi çalışmasıdır.

## Özellikler
- Ürün listeleme
- Kategori ve marka filtreleme
- Ürün arama
- Sepet sistemi
- Favori ürünler
- Koyu tema
- Responsive tasarım

## Teknolojiler
- HTML5
- CSS3
- JavaScript
